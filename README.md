# JIVANIRA Aqua Industries

Official corporate single-page website for **JIVANIRA**, an upcoming packaged drinking water enterprise by **Jivanira Aqua Industries**, founded by **Sandip Dolai** in **Dabadari, Paschim Medinipur, West Bengal, India**.

**Brand Tagline:** *Pure Refreshment. A Better Tomorrow.*  
**Planned Commercial Launch:** 2027 (Proposed – Pre-establishment Stage)

---

## 🌊 Overview

This website serves as the primary digital identity for JIVANIRA ahead of its commercial launch in 2027. It provides transparent information regarding the brand vision, planned product packaging (500 ml & 1 Litre), multi-barrier quality framework, sustainability priorities, and regional commercial partnership opportunities.

### Key Sections
1. **Hero**: Brand positioning, official cresting wave logo, 2027 launch status, and studio duo bottle packshots.
2. **About Us**: Enterprise overview, founder Sandip Dolai profile, Mission, Vision, and 5 Core Values (*Quality, Trust, Responsibility, Consistency, Growth*).
3. **Products**: JIVANIRA 500 ml (On-the-go Pack) and 1 Litre (Everyday Household & Workplace Pack) with contextual use-case mappings and future formats preview.
4. **Our Quality**: 6-pillar multi-stage purification framework featuring the planned 500 LPH industrial RO & filtration plant setup.
5. **Sustainability**: Natural water source stewardship, wastewater management, 100% recyclable PET adoption, and EPR compliance roadmap.
6. **Business Partnership**: B2B engagement tiers for regional distributors, grocery retailers, wholesalers, and institutional buyers.
7. **Contact Us**: Enterprise coordinates and an interactive validated pre-launch enquiry form.
8. **Statutory & Legal**: Accessible in-page modals for Privacy Policy and Terms & Conditions.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, TypeScript)
- **UI Library:** [Material UI (MUI v5)](https://mui.com/)
- **CSS-in-JS:** Emotion + Next.js AppRouterCacheProvider
- **Icons:** `@mui/icons-material`
- **Forms & Validation:** React Hook Form + Zod

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.x or later)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/jivanira-aqua-industries.git

# Navigate into the project directory
cd jivanira-aqua-industries

# Install dependencies
npm install
```

### Running Locally

```bash
# Run development server
npm run dev

# Open http://localhost:3000 in your browser
```

### Production Build

```bash
# Create optimized production build
npm run build

# Start production server
npm run start
```
